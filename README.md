# SAWHost — منصة استضافة المواقع

بوت تيليجرام احترافي لاستضافة المواقع الثابتة.

## البوت والويب
البوت بوابة خفيفة: «افتح لوحة التحكم»، «عن المنصة»، «الدعم الفني»، و«لوحة تحكم الأدمن» للأدمن فقط. كل الباقي (رفع، ملفات، دومينات، نسخ، GitHub، اشتراك، دعوات) داخل لوحة الويب `/panel`.

## المميزات
- 🚀 رفع موقعك بملف ZIP مباشرة
- 🌐 دومين فرعي تلقائي
- 📁 مدير ملفات كامل
- 💾 نسخ احتياطية
- 💳 اشتراكات بالدينار العراقي
- 🛡 لوحة تحكم للأدمن

## النشر على HuggingFace

### 1. أضف الـ Secrets
`BOT_TOKEN` · `ADMIN_ID` · `WEBHOOK_BASE_URL` (عنوان الـ Space) · `WEBHOOK_SECRET` (16+ حرفاً) · `SECRET_KEY` (32+ حرفاً، ثابت) · `PORT=7860`
ثم بعد ضبط الدومين: `PUBLIC_DOMAIN=sawhost.de5.net` و`EDGE_SECRET`.
**لا توجد أي بيانات دخول مدمجة في الكود.** الأدمن يدخل من تيليجرام بهويته الموقَّعة. الدخول بكلمة مرور اختياري (`ADMIN_WEB_USER` + `ADMIN_PASS_HASH` من `tools/make_admin_hash.py`).

### الدومين الخاص sawhost.de5.net
HuggingFace لا يربط دومينات خاصة مباشرة، لذلك نستخدم Cloudflare Worker (مجاني):
1. أضف `sawhost.de5.net` إلى Cloudflare ووجّه الـ Nameservers إليه.
2. Workers → أنشئ Worker والصق `cloudflare/worker.js`، وعيّن `ORIGIN=https://sawhost-sawhost.hf.space` و`EDGE_SECRET` (Secret).
3. Routes: `sawhost.de5.net/*` (و`*.sawhost.de5.net/*` لعزل المواقع) ← هذا الـ Worker، وسجل DNS (A=192.0.2.1، Proxied) للاسم و`*`.
4. في HF Secrets: `PUBLIC_DOMAIN=sawhost.de5.net` و`EDGE_SECRET` (نفس القيمة) و(اختياري) `SITES_DOMAIN=sawhost.de5.net`، ثم أعد التشغيل.
الويب هوك يبقى على عنوان الـ Space، أما كل روابط المستخدمين وزر اللوحة في البوت فتستخدم الدومين الخاص. تحقق من «النظام والإعدادات» في لوحة الأدمن.

### 2. فعّل Persistent Storage
Settings → Persistent storage → Enable

يُخزَّن في `/data`:
- `/data/sawhost.db` — قاعدة البيانات
- `/data/sites/` — ملفات المواقع
- `/data/backups/` — النسخ الاحتياطية

### 3. لوحة الويب
`https://sawhost-sawhost.hf.space/panel/`

داخل تيليجرام: زر «🖥 لوحة الويب» في قائمة البوت يفتح اللوحة كتطبيق مصغّر (Mini App) بدخول تلقائي.
في المتصفح: أرسل `/login` للبوت واكتب الرمز في اللوحة (أو اضغط زر الدخول المباشر). الأدمن يدخل من تبويب «الأدمن» في صفحة الدخول باسم المستخدم وكلمة المرور.
مسارات `/dashboard` القديمة تحوّل الآن إلى قسم الإدارة في اللوحة.

### 4. الدومين الافتراضي
بعد التشغيل: `/admin` ← **تعديل نصوص البوت** ← **دومين المنصة**

### الاشتراك والصلاحيات
- بدون اشتراك فعّال (أو تجربة): لا نشر ولا تشغيل ولا رفع ولا تعديل، من البوت أو من اللوحة. يبقى مسموحاً: الدخول، رؤية الخطط والاشتراك، تنزيل الملفات، وحذف المواقع.
- عند انتهاء `expires_at` تنزل الحدود تلقائياً للخطة الافتراضية «بدون اشتراك».
- مهمة خلفية كل 30 دقيقة توقف مواقع من لا يملك اشتراكاً فعّالاً (الأدمن مستثنى). لتعطيلها: `ENFORCE_EXPIRY=0`.

## الأمان والتكامل (الإصدار 2.0)

**حماية اللوحة من المواقع المستضافة (نفس الأصل `/s/…`)**
- رمز CSRF مرتبط بالجلسة يُسلَّم فقط لتنقّلات المتصفح الحقيقية (`Sec-Fetch-Dest: document` + `navigate`)، وكل طلبات `/panel/api` تتطلب ترويسة `X-Saw-CSRF`. أي JavaScript داخل موقع مستضاف لا يستطيع قراءته.
- `COOP: same-origin`، و`frame-ancestors` بلا `'self'`، وفحص `Origin` لكل طلب غير GET، ورفض الكوكيز المكرَّرة، ومنع التطبيقات المستضافة من كتابة كوكي `sw_session`.
- إلغاء الجلسات (`/logout-all`) عبر `sessions_valid_after`، وسجل تدقيق للإجراءات الإدارية.
- الأرشيفات: تجاهل الروابط الرمزية، سقف للملف/العدد/المساحة، رفض أي مسار يمرّ عبر رابط رمزي؛ التصدير والنسخ الاحتياطي لا يتبعان الروابط.
- العمليات: سجلات في ملفات (لا PIPE معلّق)، وعند التشغيل كـ root يُسقَط الامتياز إلى UID مستقل لكل موقع (مجلد 0700).
- ملاحظة: المتصفحات القديمة التي لا ترسل ترويسات `Sec-Fetch-*` (قبل iOS 16.4) ستُرفض عمداً.

**GitHub**: فحص المستودع والفروع، مستودعات خاصة بتوكن مشفَّر (encrypt-then-MAC من `SECRET_KEY`)، مزامنة بـ SHA فعلي، مجلد فرعي، حذف الملفات المحذوفة من المستودع (من ملفات المزامنة فقط)، سجل مزامنات، إنشاء/حذف Webhook تلقائياً، واستقبال موقَّع HMAC-SHA256 بسقف 1MB ومعالجة بالخلفية.

**إشعار الطلبات**: بطاقة تصل للأدمن في تيليجرام بأزرار قبول / رفض (أسباب جاهزة) / الملف الشخصي / فتح اللوحة.

**مهم قبل الإنتاج**: عيّن `ADMIN_PASS_HASH` و`ADMIN_WEB_USER` كـ Secrets (القيمة الافتراضية مدمجة بالكود)، و`SECRET_KEY` طويلاً وثابتاً (تغييره يُبطل توكنات GitHub المحفوظة).
